STEM MIXER - Vocal Remover, Stem Splitter, Pitch & Tempo
=========================================================
Ada 2 versi dengan mesin AI yang sama:
  - Versi WEB LOKAL  (web.bat)  -> tampilan di browser, drag & drop lagu.
  - Versi DESKTOP    (run.bat)  -> jendela aplikasi biasa.
Keduanya berjalan 100% di PC Anda dan berbagi pustaka lagu yang sama.

INSTALASI (Windows, sekali saja)
1. Pasang Python 3.11 dari https://www.python.org/downloads/
   -> saat instal, centang "Add Python to PATH".
2. Ekstrak folder ini, lalu klik dua kali  install.bat
   (mengunduh ±1-3 GB library; tunggu sampai selesai).
3. Buka aplikasi:
   - web.bat  -> browser terbuka otomatis di http://localhost:8765
                 (biarkan jendela hitam tetap terbuka; tutup untuk mematikan)
   - run.bat  -> versi desktop

MEMBUAT .EXE (opsional, setelah install.bat)
4. Klik dua kali  build_exe.bat , pilih 1 (web) atau 2 (desktop). ±5-15 menit.
5. Hasilnya di folder  dist\StemMixerWeb  atau  dist\StemMixer .
   Folder itu (±1-3 GB karena berisi mesin AI) bisa di-zip dan dipakai di
   PC Windows lain tanpa Python. Buat shortcut .exe-nya ke Desktop.

Mac/Linux:  python3 -m venv venv && source venv/bin/activate
            pip install -r requirements.txt
            python server.py   (web)   atau   python app.py   (desktop)

CARA PAKAI
1. Pilih model, lalu masukkan lagu (mp3, wav, flac, m4a, ...).
   - Pertama kali, model AI (±80 MB) diunduh otomatis.
   - Lagu 4 menit: ±1-3 menit dengan GPU NVIDIA, ±3-10 menit dengan CPU.
   - Hasil disimpan di folder  StemMixer  di folder user Anda, jadi lagu
     yang sama langsung terbuka lagi dari Pustaka tanpa diproses ulang.
2. Mixer: geser volume tiap stem 0-150%. 0 = suara hilang.
   M = Mute, S = Solo. Tombol cepat: Karaoke, Hanya vokal, Tanpa bass, Tanpa drum.
3. Pitch: -12 s/d +12 semitone (2 semitone = 1 nada). Tempo: 50-150%.
   Klik "Terapkan" (perlu beberapa detik). Pitch dan tempo independen.
4. Spasi = putar/jeda. Unduh hasil mix atau tiap stem sebagai WAV.

MODEL
- Standar (htdemucs): cepat, 4 stem - pilihan awal yang bagus.
- Kualitas tinggi (htdemucs_ft): hasil lebih bersih, ±4x lebih lambat.
- 6 stem (htdemucs_6s): tambahan gitar & piano (piano kurang akurat).
